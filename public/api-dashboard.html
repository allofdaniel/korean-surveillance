23개 연계 인터페이스 개발 현황 & 진단 (한 줄 요약)
1. 한반도 광역 항적 정보 (7개 인터페이스 - 100% 가동)
01항적정보(융합)OpenSky 실시간 ADS-B 수신 데이터를 유로컨트롤 ASTERIX Cat.062 표준 JSON으로 즉시 변환[완료]
02항적정보(개별)개별 항공기 기하학적 고도, 방위각, 지상속도 포함 ASTERIX Cat.021 타겟 리포트 생성[완료]
03Radar 합성 항적1차(PSR) 및 2차(SSR) 레이더 합성 극좌표계(Rho/Theta) ASTERIX Cat.048 변환[완료]
04지상이동체 항적G-SMGCS 공항 표면 감시 및 유도로 지상이동체 ASTERIX Cat.010 변환[완료]
05레이더 상태정보Mode-S North Mark 및 레이더 안테나 회전 주기별 ASTERIX Cat.034 상태 메시지[완료]
06PSR 단독 레이더1차 감시 레이더 단독 탐지 표적 ASTERIX Cat.048 레포트 생성[완료]
07SSR 단독 레이더2차 감시 레이더(Mode-A/C/S) 단독 탐지 표적 ASTERIX Cat.048 레포트 생성[완료]
2. 기상·NOTAM·스케줄 정보 (7개 인터페이스 - 100% 가동)
08실시간 AMOS전국 42개 활주로 센서의 1~2초 초단위 순간풍/RVR/시정/QNH/기온 등 55개 필드 전수 실시간 릴레이[완료]

10공항예보 (TAF)전국 15개 공항 24/30시간 예보 기상문을 ICAO AMHS X.400 IPM XML 전문으로 패키징[완료]
11위험특보 (SIGMET)인천 FIR 전역 중증 난기류/착빙 위험특보 ICAO AMHS IPM XML 전문 생성[완료]
12디지털기상 (IWXXM)WMO/ICAO IWXXM XML 기상전문 바이너리(FTBP Gzip Hex) AMHS 패키징[완료]

14운항스케줄 (FIDS)UBIKAIS 전국 15개 공항 실시간 출/도착 전광판 운항스케줄 전수 연동[완료]
3. 비행계획 변동 전문 (6개 인터페이스 - 템플릿 완료, 상태머신 워커 연계 대상)

19출발보 (DEP)ADS-B 이륙 또는 ATD 감지 시 ICAO DEP SOAP XML 생성 (향후 24시간 감지 워커 구축 대상)[워커대상]
